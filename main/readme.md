# ESP-IDF Platform Main Application

This directory contains the main application entry point for the **ESP-IDF platform** (e.g., ESP32, ESP32-S3).

-   `main.c`: The main application logic for the ESP32 platform starts here.
-   `CMakeLists.txt`: This file configures the ESP-IDF build system, specifying which source files and include directories are part of the main component.
